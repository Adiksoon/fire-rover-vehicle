# Role zespolu

## Hardware Team

Zakres odpowiedzialnosci:
- konstrukcja mechaniczna robota (podwozie, montaz elementow),
- dobor i integracja napedu, sterownikow, enkoderow oraz zasilania,
- okablowanie i schemat elektryczny.

Wynik pracy:
- dzialajaca platforma sprzetowa gotowa do testow z oprogramowaniem.

## Software Team

Zakres odpowiedzialnosci:
- konfiguracja i utrzymanie srodowiska ROS2,
- percepcja (kamera + marker ArUco),
- lokalizacja, SLAM, nawigacja i planowanie trasy,
- sterowanie ruchem oraz integracja z warstwa hardware.

Wynik pracy:
- dzialajacy pipeline software od detekcji celu do autonomicznego dojazdu.
