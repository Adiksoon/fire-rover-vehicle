# Autonomous Tracked Vehicle

Projekt zespolowy: autonomiczny robot mobilny (gasienicowy) do mapowania otoczenia i dojazdu do celu oznaczonego markerem ArUco.

## Zakres

- hardware: konstrukcja, naped, zasilanie, integracja czujnikow
- software: ROS2, detekcja celu, lokalizacja, planowanie trasy, sterowanie ruchem

## Technologie

- Ubuntu 22.04
- ROS2
- NVIDIA Jetson
- OpenCV
- SLAM i path planning
